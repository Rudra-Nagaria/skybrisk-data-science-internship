# Week 1: Python Programming Basics

## Topics covered
- **Variables and data types:** store temperature readings as floating-point numbers.
- **Constants:** use named values to define the accepted temperature range.
- **Input and output:** collect readings with `input()` and display results with `print()`.
- **Conditionals:** use `if` statements to validate readings and handle an empty list.
- **Loops:** use a `while` loop to collect readings and a `for` loop to print conversions.
- **Operators:** use arithmetic operators for calculations and comparisons for validation.
- **Functions:** separate conversion, input collection, report generation, and program execution.
- **Error handling:** use `try`/`except` to reject non-numeric input without crashing.
- **Lists and built-in functions:** store readings and use `sum()`, `min()`, `max()`, and `len()`.

## Project: Temperature Data Processor
The program accepts multiple Celsius readings, validates input, calculates the average, highest, and lowest readings, converts each reading to Fahrenheit, and saves a report to `temperature_report.txt`.
